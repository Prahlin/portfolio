About Dev

My Core Beliefs

Vision

Without imagination, there is no working prototype, and without a working prototype, there is no final build.

Modernness

Progressive, forward-thinking products leave room for bold options before the system narrows toward delivery.

Interconnectedness

Art, science, design, and code work best when they are treated as one shared product language.

User-friendliness

Products should be simple enough to explain clearly and polished enough to feel understood.

Cohesiveness

The weakest points deserve direct attention because the whole build depends on them holding together.
